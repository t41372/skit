## 值從哪裡來 [#where-a-value-comes-from]

最高者勝出：

1. 本次執行的 `--set NAME=VALUE`（或你在啟動選單中輸入的內容）
2. 套用的預設（`-p NAME`）
3. 上次使用的值
4. 參數宣告的預設值

如果一個必填參數在任何來源都沒有值，非互動執行會以結束碼 125 失敗 ——
skit 從不猜測。

## 預設值來自程式 [#defaults-come-from-the-script]

啟動選單用程式**目前**的預設值預先填入每個參數。skit 每次都重新讀取原始檔，
因此在程式中修改一個常數會立刻更新選單。`skit params --resync` 會把更新後的
定義寫回去。清除覆寫值即可使用程式目前的值。

當 CLI 解析器的預設值指向一個常數時
（argparse/click/typer/`parseArgs` 中的 `default=DEFAULT_HOST`），
skit 會把它解析為字面值 —— 但只有當這個名稱在檔案中恰好繫結一次，
並且看起來不像機密值時才會這樣做。看起來像機密值的常數，
其字面值從不離開程式自身的文字。

## 空就是空 [#empty-means-empty]

欄位到達時已用預設值預先填入，因此清空一個欄位是刻意為之：
它會透過注入、環境變數或旗標傳遞一個真正的空字串（`''`）。
`--set NAME=` 在 CLI 上表達同樣的意思。對於空值不能作為取值的類型 ——
`int`、`float`、`bool`、`choice`、機密值，以及沒有預設值的參數 ——
空仍然表示「未設定」。代理可以透過 `skit show --json` 中每個欄位的
`delivers_empty` 區分這兩種情況。

## 記住了什麼 [#what-gets-remembered]

- **上次使用的值**會在下次執行時預先填回來。等於宣告預設值的提交值*不會*被儲存 ——
  這樣程式預設值未來的變更就不會被舊的一次執行掩蓋。要刻意固定某個值，
  請使用預設：預設逐字儲存該次執行，包括被清空的欄位。
- **`--` 尾端引數**（`--` 之後的額外引數）依項目記住，並在下一次不帶引數的執行中
  重播，同時在標準錯誤上給出說明。`--forget-args` 清除它；`--raw` 從不重播它。
- **執行歷史**：每個項目的狀態檔記錄上一次執行的時間、結束碼與完整的值。
- 所有這些都保存在 skit 的狀態目錄中（每個項目一個 TOML 檔）—— 參見
  [環境變數](/zh-TW/docs/environment)瞭解它在哪裡，以及如何移動它。
  移除項目會同時移除它的狀態。

## 值記號 [#value-tokens]

記號可用於任何啟動選單的值、`--set` 的值與預設的值。它們按寫下的樣子儲存，
並在每次執行時重新展開 —— 寫著 `{cwd}` 的預設永遠表示「我在哪裡執行它」。

| 記號 | 展開為 |
| --- | --- |
| `{cwd}` | 呼叫時的工作目錄 |
| `{today}` | 日期，`YYYY-MM-DD` |
| `{now}` | 時間，`HH-MM-SS` |
| `{env:NAME}` | 環境變數 `NAME` —— 變數缺少是硬錯誤（結束碼 125），而不是靜默的空值 |
| 開頭的 `~` | 家目錄 |

只有這些名稱會展開；任何其他 `{…}` 文字原樣通過，而 `{{` / `}}` 轉義為字面大括號。
例外是提示詞與命令的預留位置值，其中 `{{` 與 `}}` 逐位元組原樣通過
（具名記號仍然展開）。

多值參數還會對每一段做 shell 拆分並展開萬用字元（遞迴，以呼叫目錄為根）。
來自 CLI 的額外 `-- ARGS` **不會**再次記號化或展開萬用字元 ——
它們已經經過你的 shell。

## 機密值 [#secrets]

標示為機密的參數從不被保存：不在上次使用值中，不在預設中，也不在執行歷史中 ——
在每次狀態寫入時以結構方式強制執行，並且當你把一個已使用的參數標示為機密時
會追溯清除。機密值在 `--dry-run` 與命令顯示中被遮蔽（`•••`）。
若要完全避免輸入它們，`--env-source NAME=ENVVAR` 會在執行時從環境變數讀取該值 ——
只有變數的*名稱*會被儲存。

該值仍然會到達正在執行的行程，而且提示詞不是機密值通道：
算繪後的提示詞會進入接收代理自己的工作階段記錄。
