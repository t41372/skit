---
title: 提示詞
description: 參數化的提示詞項目，以及執行它們的執行器。
---

提示詞項目是一段可重複使用、可參數化的文字，面向 AI 編碼代理。
在啟動選單中填好它的預留位置，然後把它送給你選擇的代理：

```bash
skit add review.prompt.md            # 受管預留位置成為輸入欄位
skit run review                      # 選擇代理，填寫輸入，開始
skit run review --runner codex --set target=src/app.py --no-input
```

## 新增一個 [#adding-one]

`.prompt.md`（或 `.prompt`）檔案會直接被辨識為提示詞。一般的 `.md` 也可以 ——
互動式時 skit 會詢問是否作為提示詞新增（預設為是）；非互動式時它從不猜測，
因此請傳入 `--prompt`。你也可以用 `skit add --prompt` 從零草擬一個。

## 預留位置 [#placeholders]

最多 30 個偵測到的 `{{placeholders}}` 會成為輸入欄位。當偵測數量超過 30 時，
預設不管理任何一個。這條規則可以防止程式碼範例變成變數。
請使用項目設定或 `skit params --add NAME` 來管理你想要的欄位。
受管欄位獲得完整的預設、上次使用值與 `--set` 體驗。

沒有需要學習的轉義序列：任何不是你所管理的預留位置的內容 ——
包括未受管的 `{{holes}}` —— 都逐位元組原樣傳給代理。
依提示詞的開關（`--no-interpolate`，或項目設定中的 true/false 欄位）
可以完全關閉插入。

## 執行器 [#runners]

**執行器**是接收算繪後提示詞的代理 CLI。有八個預先設定好 ——
首次使用時寫入，之後由你編輯：

| 執行器 | 命令 |
| --- | --- |
| `claude` | `claude -- {{prompt}}` |
| `codex` | `codex -- {{prompt}}` |
| `opencode` | `opencode --prompt={{prompt}}` |
| `amp` | `amp -x {{prompt}}` |
| `antigravity` | `agy --prompt-interactive {{prompt}}` |
| `copilot` | `copilot --interactive={{prompt}}` |
| `cursor` | `cursor-agent -- agent {{prompt}}` |
| `pi` | `pi {{prompt}}` |

在那些 CLI 支援的地方，`--` / `=` 繫結形式是刻意選擇的：
它們可以防止以 `--help` 或 `--model` 開頭的提示詞被解析成選項。
Cursor 固定的 `agent` 子命令同樣可以防止像 `status` 這樣的開頭提示詞
被派送成另一個 Cursor 命令。所有這些都會用提示詞作為開場訊息開啟代理的
互動工作階段 —— 除了 amp，它沒有這種模式，因此使用官方的 `amp -x`
一次性執行提示詞並返回。

Pi 的位置引數解析器既沒有選項結束分隔符，也沒有繫結的提示詞選項。
如果算繪後的提示詞以 `-` 或 `@` 開頭，或者恰好等於 Pi 的某個套件命令，
skit 會警告並在啟動前加上一個換行字元。這個非無損的回退方案讓 Pi 保持互動模式，
並防止它把提示詞當作選項、附件或套件操作。同樣的警告與回退也適用於
非互動式的 skit 執行。

用下面的方式登錄其他執行器：

```bash
skit runner add mycli -- mycli run {{prompt}}
```

範本規則：每個詞是一個 argv 引數（任何地方都不經過 shell）；
必須正好有一個引數是 `{{prompt}}`；它不能是第一個引數（那是執行檔）；
不允許其他 `{{holes}}`；單大括號文字是字面值。

執行器如何被選擇：

- **互動式執行**：在啟動選單中選擇，並以你上次的選擇預先填入。
  你沒有改動的固定值不算一次選擇。
- **非互動式執行**：`--runner` 勝過項目的固定值；兩者都沒有時，
  執行以結束碼 126 失敗。這裡刻意沒有全域預設值，也沒有排序 ——
  執行器改變的是*結果*。上次的選擇只用於預先填入互動式表單，
  它從不解析 `--no-input` 的執行。
- 每次執行的代理選項跟在 `--` 之後：`skit run review -- --model opus`。
  這些尾端引數像任何項目一樣被記住 —— 參見
  [參數與值](/zh-TW/docs/parameters#what-gets-remembered)。

## 傳遞 [#delivery]

執行一個提示詞會算繪文字，並用它呼叫所選執行器已設定的 argv 命令。
算繪後的提示詞作為單一行程引數傳遞 —— 中間沒有 shell，
因此文字中的任何內容都不會被 shell 解讀。

過大的提示詞在啟動前就會被拒絕，並給出說明測得大小的清晰錯誤（結束碼 125），
而不是原始的作業系統失敗：組裝後的命令列上限在 Windows 上是 60,000 個
UTF-16 單元，在 POSIX 上是 100,000 位元組 —— 中日韓文字按位元組計，而不是字元。
算繪後的文字中出現 NUL 位元組同樣會被拒絕。

## 不是機密值通道 [#not-a-secrets-channel]

算繪後的文字包含什麼，就會進入接收代理自己的工作階段記錄。
不要把機密值放進提示詞 —— 這裡沒有任何傳遞機制會假裝不是這樣。
